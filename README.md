# Linnea Nore – Portfolio

This is my personal frontend portfolio.

I built it to show how I approach UI, UX, accessibility, and modern frontend development — not just what tools I use, but how I think when I build things.

Live site: https://linneanore.vercel.app

---

## About this project

The goal of this portfolio was to create something clean, calm, and well-crafted, with attention to details that often get overlooked — spacing, motion, accessibility, and overall feel.

I wanted it to:
- feel polished without being flashy
- be easy to navigate
- work well with keyboard and reduced motion
- reflect how I actually build projects in real life

---

## Tech stack

- React  
- TypeScript  
- Vite  
- Tailwind CSS  
- Framer Motion  

Deployed with **Vercel**.

---

## Accessibility

Accessibility is something I actively care about and work with.

This site is built with:
- semantic HTML
- keyboard navigation in mind
- WCAG-aware contrast and structure
- respectful motion (reduced motion supported)

I’ve also done a full WCAG accessibility audit as part of my thesis, which is linked from the portfolio.
